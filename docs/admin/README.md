# admin/ — the underwriter-facing console

Documentation for the Flutter admin console (`lib/screens/admin/`,
`lib/admin/`). Fourteen files covering five features, because each one was
written up three times: a guide, a quick reference, and a completion summary.

**Start with the guides.** The summaries are point-in-time reports of work
finishing and are not maintained.
