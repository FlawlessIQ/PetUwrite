Warm cream ground, ink text, forest for action and trust, one orange accent spent only on attention. The gradient belongs to the brand — mark, life-arc, score ring — never to buttons, text, or data.

Typography

Playfair Display carries emotion — headings, scores, prices, the pet's name moments. Poppins carries the interface — Light 300 for body warmth, Semibold 600 for labels and actions. Nothing else, ever; no Inter, no system-font drift.

Components

Radii: cards 22px, inner cards 18px, wells and inputs 12px, everything tappable-pill 999px. Shadows: soft for resting cards, lift for modals and the phone frame. Borders always line, 1px.

Buttons — pill only, verb labels

Primary = forest. Payment/commitment = ink-dark. Secondary = ghost. One primary per screen. Never gradient, never accent-orange buttons.

Chips & status

✓ Coverage active now · worth watching habit Blue sky Built

Green sage = good/active. Amber = attention, never alarm-red (reserve red for destructive actions only). Status always icon-or-word + color, never color alone.

Companion conversation kit — typed blocks, never free text

Max has been limping a little after our walks. Should I be worried?
Worth paying attention to.
From Max's history: mild hip laxity noted, March 2024.
Watch for morning stiffness and reluctance on stairs. Worth a vet's eyes — not an emergency, but soon.
Companion informs and routes to licensed vets — it doesn't diagnose. Conversations are never used in underwriting or claims.

The companion can only speak through typed blocks — text · history_ref · watch_signs · actions · booking_confirm · product_ref · escalate · fact — each rendered by a spec'd component. Free markdown is never rendered, so every reply is on-brand by construction, and compliance lives in the component set: no diagnosis component exists. The disclaimer is screen chrome, not model output — it can't be omitted. Full schema and specs: DESIGN.md §5b.

ElementSpec
IconsOutline style, 1.7px stroke (2.1px active), round caps/joins, 20–24px grid. No filled icon sets, no emoji as UI icons (emoji allowed in content/product imagery placeholders only).
Spacing4px base grid. Card padding 14–24px. Section rhythm 46–72px. Gaps via flex/grid gap, not margins.
Motion150ms hover / 300ms transitions, ease. One orchestrated moment per screen (the projection shifting). Respect prefers-reduced-motion always.
Focus2.5px forest outline, 2px offset, on every interactive element.
Data vizData marks = forest; attention series = accent; grid/track #EDEAE0; never the gradient, never rainbow. Ranges shown as bands, endpoints emphasized. Evidence badges (strong / associational / directional) accompany any health claim chart.

Voice

Say

"More good years, together." · "On track for 12–14 healthy years." · "Worth a look, not an emergency." · "Here's why this was picked for Max." · "The evidence for this is mixed — we'll say so." · Verb buttons: "Protect Max," "Book," "See his plan."

Never

"Lifecycle" · "platform" · standalone "wellness" in customer copy · lifespan promises or countdowns · diagnosis language ("Max has…") · alarm framing · treatment claims on products · premium-linked reward language · "Submit" buttons.

The ten rules

1One mark file. Everything derives from clovara_mark_refined.svg.
2Gradient = brand moments only (mark, score ring, life-arc). Never buttons, chrome, or data.
3Accent orange is attention, spent sparingly. If everything glows, nothing does.
4Playfair for feeling, Poppins for function. No third face.
5Cream ground, white cards, line borders, soft shadows. Depth is quiet.
6Pills for everything tappable. One forest primary per screen.
7The pet's name appears wherever the system speaks — it's his plan, not "your dashboard."
8Honesty is visual: evidence badges, "illustrative" labels, and "simulated" captions are design elements, not disclaimers to hide.
9Calm always: amber before red, questions before alarms, ranges before point estimates.
10When in doubt, remove one thing.
